## 🎮 게임 소개

장애물을 피해 달리는 **러닝 액션 게임**.
캐릭터를 조작하며 다양한 스테이지를 클리어하는 방식으로 진행됩니다.

| 항목 | 내용 |
|------|------|
| **장르** | 러닝 게임 |
| **플랫폼** | — |
| **개발 기간** | 2022.02 – 2022.07 |
| **팀 구성** | 팀 프로젝트 |
| **담당 역할** | 게임 클라이언트 프로그래머 |
| **기술 스택** | Unity · C# |
